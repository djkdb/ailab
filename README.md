# ZUN AI Roadmap

> **AI 레벨을 올리는 가장 확실한 방법.**
> Zero → Up → Next.

AI 완전 초보를 고급 사용자로 성장시키는 학습 플랫폼입니다.
"ChatGPT가 있다는 건 아는데, 어떻게 써야 할지 모르겠어요"라는 사람을 위해
모든 여정이 0에서 시작하도록 설계했어요.

Duolingo + Codecademy + LeetCode + Notion — 그러나 AI를 위해.

## 핵심 루프

1. **🎯 AI 실력 진단** — 20개의 실제 상황으로 5가지 역량을 측정해요.
   - 질문력 · 프롬프트 작성 · 도구 선택(GPT/Claude/Gemini) · 정보 검증 · 자동화 사고
   - 결과: **"당신의 AI 레벨: 18 / 100 (ZERO)"**
   - **찍어서 올릴 수 없는 진단** — 고르는 문항 17개 + 프롬프트를 직접 쓰는 실기 3개.
     실기는 프롬프트 분석기가 채점하고, 선택 문항은 보기 길이·정답 위치 편향을 제거했어요.
     지식 없이 찍으면 레벨 23~27(무작위 기댓값)에서 멈춥니다 — `tools/check-diagnostic.py`로 검증해요.
2. **🗺️ 맞춤 로드맵** — 약한 역량에 맞춰 시작 지점과 집중 레벨이 정해져요.
3. **📈 레벨 업** — 레슨을 완료할 때마다 AI 레벨·XP·배지가 쌓이고 다음 레슨이 열려요.
   - 진단만으로는 레벨 60까지. **NEXT(75+)는 실전으로만 도달**할 수 있어요.

## 학습 경로 (20 레벨)

| 구간 | 레벨 | 내용 |
|---|---|---|
| **ZERO** | 1–5 | AI란 무엇인가 · 질문하는 법 · 프롬프트 기초 · 프롬프트 엔지니어링 · ChatGPT |
| **UP** | 6–10 | Claude · Gemini · 이미지 생성 · 영상 생성 · 딥 리서치 |
| **NEXT** | 11–15 | 자동화 · AI 코딩 · Claude Code · MCP · AI 에이전트 |
| **NEXT 심화** | 16–20 | AI 워크플로 설계 · 나만의 AI 비서 · 팀과 함께 쓰기 · 검증과 책임 · 나만의 AI 시스템 |

모든 레슨은 같은 구조예요:
**배우기 → 좋은 예 vs 나쁜 예 → 인터랙티브 연습 → AI 실전(시뮬레이션) → 퀴즈 → XP 보상 → 다음 레슨 해제**

## 기능

- 📖 **프롬프트 도서관** — 실전 프롬프트 40개(8개 분야). 검색·저장·내 보관함 지원.
  각 프롬프트가 **왜** 좋은지 분석기가 요소별로 뜯어서 보여줘요 (평균 85점)
- 🔬 **프롬프트 분석기** — 역할·맥락·형식 등 7가지 기준으로 점수 + 진단 + 자동 개선
- ⚖️ **AI 도구 비교** — 상황을 고르면 ChatGPT / Claude / Gemini 중 추천
- 🎮 **플레이그라운드** — 같은 상황, 다른 프롬프트의 결과 차이를 직접 체험
- 📕 **오답노트** — 틀린 퀴즈만 모아 다시 풀어요. 맞히면 사라지고, 또 틀리면 남아요
- 🏆 **오늘의 도전** — 매일 5분, 실제 AI 도구로 해보는 미션
- 🔥 스트릭 · ⭐ XP · 🎖️ 배지 13종 · RPG식 레벨 진행
- 📸 **공유 카드** — 진단 결과와 레슨 완료를 인스타 규격(1080×1080) 이미지로 저장

## 실행

빌드도, 설치도, 서버도 필요 없어요.

```bash
# 그냥 열기
open index.html

# 또는 로컬 서버
python3 -m http.server 8000
```

GitHub Pages에 그대로 배포할 수 있어요 (정적 파일만 사용, 절대 경로 없음).
학습 기록은 브라우저 localStorage에만 저장돼요.

> **다른 도메인에 올린다면** `index.html`의 `og:url` · `og:image` · `twitter:image`
> 호스트를 바꿔야 카카오톡·트위터 링크 미리보기 썸네일이 나옵니다.
> 기본값은 `https://djkdb.github.io/ailab/` 기준이에요.

### 사용자 기록은 언제 사라지나요

기록은 브라우저 localStorage(`zun_ai_roadmap_v1`)에 도메인 단위로 저장돼요.

- **앱을 업데이트해도 안 지워집니다.** 파일을 새로 올리는 것과 저장소는 무관해요.
  상태 형태가 바뀌어도 `normalize()`가 옛 기록을 그대로 받아줍니다.
- 사라지는 경우는 이렇습니다.
  1. **인앱 브라우저** — 인스타·카톡에서 연 창은 저장소가 분리돼 있고 닫으면 날아갈 수 있어요.
     그래서 인앱으로 접속하면 상단에 "기본 브라우저로 열어주세요" 경고가 뜹니다.
  2. **방문 기록·사이트 데이터 삭제**, 시크릿 모드, 다른 기기·다른 브라우저
  3. iOS Safari는 **7일간 방문이 없으면** 저장소를 정리할 수 있어요
- 대비책은 **내 성장 → 기록 백업 저장**입니다. JSON 파일로 내려받고
  **백업 불러오기**로 다른 기기에서 그대로 복원할 수 있어요.
- 도메인을 바꾸면(예: GitHub Pages → 커스텀 도메인) 저장소가 달라서
  기존 사용자 기록이 안 보입니다. 옮기기 전에 백업을 안내해 주세요.

## 구조

```
index.html              # SPA 셸 (해시 라우팅)
assets/css/main.css     # 디자인 시스템 (Apple 디자인 분석 기반)
assets/js/engine.js     # 상태·레벨·XP·스트릭·배지·프롬프트 분석기
assets/js/app.js        # 라우터
assets/js/views-*.js    # 홈·진단·로드맵·레슨·랩·도전·프로필
assets/js/data/         # 레슨 20개 · 진단 20문항 · 도전 30개 · 프롬프트 40개
assets/og-image.png     # 링크 미리보기 이미지 (1200×630)
tools/check-diagnostic.py  # 진단 문항의 '찍기 가능성' 검사 — 문항 수정 후 실행
```

## 품질 기준

문항이나 화면을 고친 뒤에는 아래를 지켜주세요.

- **진단 문항** — `python3 tools/check-diagnostic.py`가 통과해야 해요.
  3점 보기가 최장인 비율이 35%를 넘거나, 찍기 전략이 무작위보다 유리하면 실패합니다.
- **색 대비** — 본문 텍스트는 4.5:1, 24px 이상 큰 글씨는 3:1 이상.
  다크 타일 위에서는 `--on-dark-dim` · `--blue-on-tile`을 쓰세요
  (흰 배경용 `--ink-48` · `--blue`를 그대로 쓰면 대비가 무너져요).
- **터치 영역** — 손가락으로 누르는 기기에서 44px 이상. `@media (pointer: coarse)` 블록에서 관리해요.
- **저장 상태** — 형태가 깨진 localStorage에도 화면이 죽지 않아야 해요.
  `engine.js`의 `normalize()`가 타입을 강제하고, 렌더가 터지면 `app.js`가 복구 화면을 보여줍니다.
